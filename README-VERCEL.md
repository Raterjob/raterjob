# RaterJob — Vercel package

This package contains the Vercel-ready version of RaterJob.

## Deploy

1. Extract the ZIP.
2. Upload the extracted folder to a Git repository, or open it in a terminal.
3. Import the repository into Vercel, or run `npx vercel` from this folder.
4. Keep the framework preset set to **Next.js** and leave the build command as `next build`.

No Cloudflare, Wrangler, Vinext, or ChatGPT Sites configuration is included.
