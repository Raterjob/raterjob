## Caricamento su GitHub

Estrai lo ZIP e carica nella radice del repository tutti i file e le cartelle contenuti al suo interno. Non caricare lo ZIP e non inserire l'intero progetto dentro una sottocartella.

Vercel deve usare il branch `main`, il framework Next.js e Node.js 22.
